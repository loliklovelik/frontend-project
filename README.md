# Frontend Development

> Учебный проект по курсу повышения квалификации  
> **Тема**: Разработка веб-интерфейсов с использованием HTML, CSS и JavaScript


## 📖 О проекте

Этот репозиторий — сборник моих практических работ, выполненных в рамках курса повышения квалификации по направлению "Frontend-разработка".


### Внутри:

- **Стихотворная страница** — пример работы с встроенными стилями и типографикой
- **Слайдер изображений** — чистый CSS-слайдер без JavaScript
- **Обработка массивов** — функции высшего порядка и колбэки
- **ООП на JS** — классы, наследование, полиморфизм
- **Работа с API** — асинхронные запросы и обработка ошибок

## Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Стилизация**: Flexbox, CSS-анимации, медиа-запросы
- **JS-паттерны**: ООП, функциональное программирование, асинхронность

В ходе обучения были освоены и применены на практике:

- **Структурирование веб-страниц** с использованием семантических тегов HTML5
- **Визуальное оформление** с помощью CSS3 (Flexbox, анимации, медиа-запросы)
- **Интерактивность** на чистом JavaScript (работа с DOM, события)
- **Объектно-ориентированное программирование** в JavaScript
- **Асинхронные запросы** к API и обработка данных
- **Адаптивная верстка** под мобильные устройства
